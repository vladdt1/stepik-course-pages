# Как устроены интерактивные страницы

В Stepik встроены прямые HTML-адреса из `courses/305734-go-pro-max/`.
Параметры `lab` и `embed` сохранены: общая модель выбирает упражнение и режим
встраивания. Отдельный файл каждого упражнения позволяет держать страницы
рядом с темой и не смешивать их с введением или описанием.

Git и Docker — клиентские учебные модели, без доступа к реальному компьютеру.
Vue-лаборатории используют настоящие компоненты, реактивность, Router и Pinia;
сетевая часть отмечена как управляемая модель. Редактируемый код выполняется
в Worker с таймаутом. Сборка использует относительные адреса, включая Worker,
чтобы страницы работали в подкаталоге GitHub Pages.

Общие служебные файлы прежнего хостинга в Pages не нужны. В частности,
Cloudflare challenge не является частью интерактива и не переносится.

Локальный прогресс тренажёра хранится браузером для текущего домена. После
перехода на новый домен он начинается отдельно; ответы и баллы Stepik не меняются.
Внешние тренажёры не передают баллы в Stepik автоматически.

Публичный репозиторий содержит только страницы, необходимые общие ресурсы,
исходники лабораторий и инструменты. Ключи API, снимки курса, посылки и закрытые
решения программных задач хранятся отдельно в локальном проекте автора.
