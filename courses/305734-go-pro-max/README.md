# Go-шечка Pro MAX

Страницы одного курса: введение, описание и интерактивы Git, Docker и Vue.

В `introduction/` шесть готовых страниц. Источники — `content.mjs` и общие
шаблоны `shared/course-introductions/`. В `promo/` хранится отдельное оформление
описания и компактная анимация `project.html`.

В `modules/` страницы сгруппированы по фактическому номеру и теме модуля.
Каждый тренажёр имеет свой HTML и прямой адрес; модель и оформление общие.
Вопросы о знакомстве и цели сохраняют нативные поля ответа Stepik.

Команды сборки и просмотра — в корневом README. Старые площадки остаются
доступными; этот репозиторий не изменяет их и не содержит других учебных курсов.
