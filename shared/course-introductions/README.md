# Общие шаблоны введения

Шаблоны и оформление сохранены по образцу `Zak618/stepik-course-pages`.
В этом репозитории они используются введением курса 305734. Публичный каталог
и его обложки сохранены; другие учебные курсы и их задания сюда не перенесены.

Готовые страницы находятся в `courses/305734-go-pro-max/introduction/`.
Их текст задаётся в `content.mjs`, общие приветствие и карта — в шаблонах.
Пересборка введения: `node scripts/go-pro-max-introduction/build.mjs`.
Сборка лабораторий и общий просмотр описаны в корневом README.

Секреты и снимки API хранятся локально и не входят в репозиторий.
